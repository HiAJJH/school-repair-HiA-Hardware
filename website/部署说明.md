# 上线步骤（约 15 分钟，不用写代码）

这个文件夹里有 5 个文件，只需要动 **config.js** 一个文件，其余都别改。

## 你需要准备
两个免费账号（用邮箱或 GitHub 就能注册）：
1. **Supabase**（免费数据库）→ https://supabase.com
2. **Netlify**（免费网页托管）→ https://www.netlify.com

---

## 第一步：建数据库（Supabase）

1. 打开 https://supabase.com ，点 **Start your project** 注册登录。
2. 点 **New project**，随便填个名字（如 `school-repair`），设置一个数据库密码（记好），地区选离你近的（如 Singapore 或 Tokyo），然后 **Create**，等 1-2 分钟建好。
3. 左侧菜单点 **SQL Editor** → **New query**。
4. 把本文件夹里 **建表.sql** 的内容**全部复制粘贴**进去，点右下角 **Run**。出现 "Success" 即成功。

## 第二步：创建管理员账号

1. 左侧菜单点 **Authentication** → **Users**。
2. 点 **Add user** → **Create new user**。
3. 填一个邮箱（你的邮箱）和密码（自己设，比如 `Aa123456`），**勾选 Auto Confirm User**，点 **Create user**。
   - 这个邮箱+密码就是以后打开"管理后台"时登录用的。

## 第三步：拿到两串钥匙，填进 config.js

1. 左侧菜单点 **Project Settings**（齿轮图标）→ **API**。
2. 复制 **Project URL**（形如 `https://xxxx.supabase.co`）和 **anon public key**（以 `eyJ` 开头的长串）。
3. 用记事本打开本文件夹的 **config.js**，把两处替换掉，同时把联系方式改成你自己的，保存。

## 第四步：发布上线（Netlify）

1. 打开 https://app.netlify.com/drop
2. 登录（第一次会提示注册）。
3. 把整个 **website 文件夹**（注意是文件夹，不是里面的单个文件）拖进网页虚线框里。
4. 几秒后生成一个网址，形如 `https://xxxx.netlify.app`，点开就能访问你的预约页面了。

---

## 第五步：使用

- **客户页面**：`https://xxxx.netlify.app`（价目表 + 预约表单，发给同学）
- **管理后台**：`https://xxxx.netlify.app/admin.html`（用第二步的邮箱密码登录，看自动统计）

管理后台里能看到：总预约数、今日新增、预计收入区间、服务类型分布、最近订单，还能一键"复制为表格"粘到 Excel 里。

---

## 常见问题

- **提交后网页提示"提交失败"**：八成是第三步的钥匙没复制对，或第一步的建表 SQL 没运行成功，回去检查。
- **登录后台提示密码错误**：去 Supabase → Authentication → Users 确认账号存在、密码正确。
- **想改价格/服务项目**：改 `index.html` 里的价目表和下拉选项，以及 `admin.html` 里开头的 PRICE 表（两处要保持一致）。
- **忘记管理密码**：去 Supabase → Authentication → Users 点该用户，重置密码即可。
